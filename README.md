# Naveed Ahmed M — Portfolio

A dual-experience interactive portfolio built with Next.js, React Three Fiber, and Framer Motion.

## Experiences

**Desktop (≥1024px)** — A cyberpunk WebGL environment with three scroll-driven scenes:
- Hero: Parallax monolith with mouse-tracked rotation
- Skills: Sci-fi server rack with post-processing glitch effects  
- Projects: Hologram projector with a 3D carousel of project cards

**Mobile (<1024px)** — A manga/anime aesthetic with three themed sections:
- Fire Force-inspired hero deck
- Attack on Titan skill disclosure interface with SVG electric borders
- One Piece voyage log with bounty-poster project cards

## Stack

- Next.js 16 / React 19
- React Three Fiber + Drei + Postprocessing
- Framer Motion
- Tailwind CSS v4
- Lenis smooth scroll
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
